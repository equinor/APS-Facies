# APS FMU Configuration File for non-standard FMU file and directory standard

## Overview

This YAML file defines the directory structure and file naming conventions used by the APS plugin when integrated with an FMU project.

When a project follows the standard FMU directory structure and standard file names, APS can use its built-in defaults and this file is not required.

For projects using a non-standard directory structure or alternative file names, this configuration file allows APS to locate FMU-related resources.

---

## File Structure

```yaml
top_directory_relative_to_rms_project: ../..
relative_paths: ...
aps_file_extensions: ...
```

## Top-Level Keywords

### `top_directory_relative_to_rms_project`

Relative path from the RMS project location to the FMU project root directory.

**Type:** string

**Example**

```yaml
top_directory_relative_to_rms_project: ../..
```

---

## Section: `relative_paths`

Defines relative paths to FMU, RMS, ERT, APS, configuration, and distribution directories.

### `fmuconfig`

Path to the FMU configuration root directory.

```yaml
fmuconfig: fmuconfig
```

### `fmu_config_input`

Directory containing FMU input configuration files.

```yaml
fmu_config_input: fmuconfig/input
```

### `fmu_config_output`

Directory containing generated FMU configuration output files.

```yaml
fmu_config_output: fmuconfig/output
```

### `global_variables_file`

Path to the YAML file containing FMU global variables.

```yaml
global_variables_file: fmuconfig/output/global_variables.yml
```

### `ert`

ERT root directory.

```yaml
ert: ert
```

### `ert_model`

Directory containing ERT model definitions.

```yaml
ert_model: ert/model
```

### `ert_dist`

Directory containing ERT distribution specifications.

```yaml
ert_dist: ert/input/distributions
```

### `rms`

RMS root directory.

```yaml
rms: rms
```

### `rms_model`

Directory containing RMS model files.

```yaml
rms_model: rms/model
```

### `rms_field`

Directory used by APS field exports.

```yaml
rms_field: rms/output/aps
```

### `aps_model_export`

Directory where APS model files are exported.

```yaml
aps_model_export: rms/input/config/apsgui
```

### `aps_initial_ensemble_path`

Location of the APS output from the initial ensemble realization.

```yaml
aps_initial_ensemble_path: ../iter-0/rms/output/aps
```

---

## Section: `aps_file_extensions`

Defines file name suffixes used by APS-generated FMU and ERT configuration files.

### `fmu_master_config`

Suffix used for APS parameter configuration files.

```yaml
fmu_master_config: _aps_params.yml
```

Suffix used for APS FMU configuration files.

```yaml
fmu_config: _aps_fmu_config.yml
```

### `ert_fields`

Suffix used for ERT field configuration files generated by APS.

```yaml
ert_fields: _aps_ert_config_fields.txt
```

### `ert_prob`

Suffix used for ERT probability/distribution configuration files generated by APS.

```yaml
ert_prob: _aps_ert_config_dist.txt
```

---

## Complete Example

```yaml
top_directory_relative_to_rms_project: ../..
relative_paths:
  fmuconfig: fmuconfig
  fmu_config_input: fmuconfig/input
  fmu_config_output: fmuconfig/output
  global_variables_file: fmuconfig/output/global_variables.yml
  ert: ert
  ert_model: ert/model
  ert_dist: ert/input/distributions
  rms: rms
  rms_model: rms/model
  rms_field: rms/output/aps
  aps_model_export: rms/input/config/apsgui
  aps_initial_ensemble_path: ../iter-0/rms/output/aps

aps_file_extensions:
  fmu_master_config: _aps_params.yml
  fmu_config: _aps_fmu_config.yml
  ert_fields: _aps_ert_config_fields.txt
  ert_prob: _aps_ert_config_dist.txt
```

## Notes

- All paths are relative to the FMU project root specified by `top_directory_relative_to_rms_project`.
- All keywords should be retained even when customized.
- Only APS-relevant FMU paths are configured in this file.
- This file is intended for projects using non-standard FMU directory layouts or alternative file naming conventions.
