---
title: Configuration of APS with AHM using ERT
---
Steps to setup an APS job for use in AHM

- Define an APS job in RMS

- Select Job Settings in APS GUI:

- Select to use APS in AHM

- Select ERTBOX grid or let APS job create it. Set max number of layers needed for ERTBOX.

- Select to automatically simulate and export GRF or import GRF fields from ERT

- If GRF trends are used somewhere, select extrapolation method for the GRF field in ERTBOX

- Turn on option to let APS generate FMU and ERT related files to simplify configuration of FMU and ERT

- Close Job Setting window

- For each zone, select grid conformity (Should be the same as used when building the grid in RMS)

- For each zone to be modelled, toggle on the APS parameters ERT should draw using GEN_KW or set by DESIGN_KW.

- Save the job

- Run the job from RMS workflow (not interactively from the Run button). Files to help setting up configuration of ERT and FMU will be created with APS job name as prefix. The files generated by APS are:

  - `<jobname>_aps_params.yml` located in `fmuconfig/input`

  - `<jobname>_aps_dist.txt` located in `ert/input/distributions`

  - `<jobname>_aps_fields,txt` located in `ert/model`

- Go to `fmuconfig/input`:

  - Edit the file `<jobname>_aps_params.yml` **if necessary (e.g if files from multiple APS jobs is to be merged together). The heading of the file contains some comments how to include the file into `global_master_config.yml`**

- Go to `ert/input/distributions`:

  - Edit the file `<jobname>_aps_dist.txt` and specify ERT probability distributions for the APS parameters to be updated / simulated by ERT.

- Go to `ert/model`:

  - Move the file `<jobname>_aps_fields.txt` to `ert/input/config` directory and rename it to e.g. _ahm_field_aps.ert_ and add an include of this in the main ERT config file or just copy the content into the ert config file.

  - Add `GEN_KW` or `DESIGN_KW` keyword for the APS parameters

  - Test it by running single realization run in ERT
