---
title: Configuration of APS
 with AHM using ERT
---
<span style='color: #243746;'><span>Steps to setup an APS job for use in AHM</span></span>- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Define an APS job in RMS</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Select Job Settings in APS GUI:</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Select to use APS in AHM</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Select ERTBOX grid or let APS job create it. Set max number of layers needed for ERTBOX.</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Select to automatically simulate and export GRF or import GRF fields from ERT</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">If GRF trends are used somewhere, select extrapolation method for the GRF field in ERTBOX</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Turn on option to let APS generate FMU and ERT related files to simplify configuration of FMU and ERT</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Close Job Setting window</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">For each zone, select grid conformity (Should be the same as used when building the grid in RMS)</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">For each zone to be modelled, toggle on the APS parameters ERT should draw using GEN_KW or set by DESIGN_KW.</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Save the job</span></font>
- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Run the job from RMS workflow (not interactively from the Run button). Files to help setting up configuration of ERT and FMU will be created with APS job name as prefix. The files generated by APS are:</span></font>

- <font color="#0070c0"><span style=" font-size:10pt; font-family:verdana; color:#0070c0; font-weight:Normal; font-style:Normal; font-decoration:Normal">&lt;jobname&gt;_aps_params.yml</span></font><font color="#243746"><span>located in fmuconfig/input</span></font>

- <font color="#0070c0"><span style=" font-size:10pt; font-family:verdana; color:#0070c0; font-weight:Normal; font-style:Normal; font-decoration:Normal">&lt;jobname&gt;_aps_dist.txt</span></font><font color="#243746"><span>located in ert/input/distributions</span></font>

- <font color="#0070c0"><span style=" font-size:10pt; font-family:verdana; color:#0070c0; font-weight:Normal; font-style:Normal; font-decoration:Normal">&lt;jobname&gt;_aps_fields,txt</span></font><font color="#333333"><span>located in ert/model</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Go to fmuconfig/input:</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Edit the file</span></font><font color="#0070c0"><span>&lt;jobname&gt;_aps_params.yml</span></font><font color="#243746"><span>if necessary (e.g if files from multiple APS jobs is to be merged together). The heading of the file contains some comments how to include the file into</span><span><b><i>global_master_config.yml</i></b></span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Go to ert/input/distributions:</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Edit the file</span></font><font color="#0070c0"><span>&lt;jobname&gt;_aps_dist.txt</span></font><font color="#243746"><span>and specify ERT probability distributions for the APS parameters to be updated/simulated by ERT.</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Go to ert/model:</span></font>

- <font color="#243746"><span style=" font-size:10pt; font-family:verdana; color:#243746; font-weight:Normal; font-style:Normal; font-decoration:Normal">Move the file</span></font><font color="#0070c0"><span>&lt;jobname&gt;_aps_fields,txt </span></font><font color="#333333"><span>to ert/input/config directory and rename it to e.g</span></font><font color="#0070c0"><span><i>ahm_field_aps.ert</i></span></font><font color="#333333"><span>and add an include of this in the main ERT config file or just copy the content into the ert config file.</span></font>

- <font color="#333333"><span style=" font-size:10pt; font-family:verdana; color:#333333; font-weight:Normal; font-style:Normal; font-decoration:Normal">Add GEN_KW or DESIGN_KW keyword for the APS parameters</span></font>

- <font color="#333333"><span style=" font-size:10pt; font-family:verdana; color:#333333; font-weight:Normal; font-style:Normal; font-decoration:Normal">Test it by running single realization run in ERT</span></font>
