---
title: Correlation ranges
---
Spatial correlation lengths parallell to azimuth direction (Main range), orthogonal to azimuth direction (Perpendicular range) or vertical direction can be specified as well as azimuth direction and dip direction.
The dip is the angle between the horizontal plane (of simulation box) and the dipped plane measured in the azimuth direction. The two angles azimuth and dip together define the direction for the main range.
