---
title: Specify Gaussian Random Fields
---
Usually APS will use two Gaussian Random Fields (GRF).
Transformed values of the GRF's are called alpha.

$\alpha_{1}$ corresponds to the horizontal axis of the truncation map while $\alpha_{2}$ corresponds to the vertical axis.

If the truncation rule also apply overlay facies,
the number of GRF's are three or more depending on how the overlay facies is specified.

The user will have to specify model parameters for each of the GRF's that are used.
